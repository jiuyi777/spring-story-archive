# 春序档案

面向 SillyTavern 1.14.0 的浏览器侧 UI Extension。当前版本为 0.5.5。核心是逐楼摘要、滚动总摘要与可选的语义回忆，剧情选项、玩家偏好分析、自主推进和 NPC 生成为辅助能力。

## 已实现的产品规则

- 每个聊天楼层都有独立记录：缺失、处理中、已摘要、失败。
- 缺失、失败和已完成记录都能单独重新生成。
- 自动摘要只处理之后新增、编辑与滑动重选的楼层，不会在打开插件、启动酒馆或切换聊天时扫完全部旧楼层。旧楼层由玩家点击“补全下一批”处理，每批可选 10 或 20 楼，默认 10 楼。
- 一批楼层只调用一次摘要 API，返回后仍拆成独立逐楼摘要。内容超过安全预算时自动拆成多批；批次之间默认间隔约 1.8 秒。遇到 429、Too many requests 或 rate limit 后立即停止后续批次，未处理楼层继续保持待补全。
- 最近 5 楼默认展开，更早楼层默认折叠；展开数量可以在摘要页顶部调整。
- 玩家输入作为完整原文记录保存在本机，并始终带有楼层顺序；它不会因为是决定、拒绝、同意、偏好或边界而获得永久权重。同一主题有后续明确表态时，以更晚楼层为当前状态，旧表态只保留为当时发生过的历史。
- 摘要页可选择剧情选项、推进导演等辅助接口不发送历史原文，或只发送最近 1、3、5 楼；默认不发送历史原文。批量逐楼摘要始终只发送本批目标楼层，不附带批次以外的历史原文。
- 摘要、剧情选项和推进导演的请求负载统一由隐私构造器生成，所有正文合计另有约 6500 token 的硬上限，过长时保留开头与结尾并省略中段。
- 更早的原文只保留在 SillyTavern 与本机 IndexedDB，不由本扩展放入额外 API 请求。
- 摘要页顶部可直接设置自动压缩 token 阈值；每满 100 楼仍会生成一次压缩总摘要。
- 摘要、选项和推进导演可以分别选择酒馆当前 API 或额外 OpenAI-compatible API。
- 额外 API Key 只写入 `sessionStorage`，关闭浏览器会话后消失；地址和模型写入扩展设置。模型列表优先从 OpenAI-compatible `/models` 接口自动读取，不支持时仍可手动输入。
- 语义回忆默认关闭。开启时先确认当前酒馆提供 `setExtensionPrompt`；开启后只把逐楼摘要、时间线、人物状态、关系和线索发送到额外 API 的 `/embeddings`。在“不发送历史原文”模式下，查询向量也从最近摘要生成，不读取聊天原文。每次酒馆正式生成前，从更早摘要中召回相关内容并通过 `setExtensionPrompt` 注入；界面明确显示等待、本轮已注入、无匹配或注入失败。嵌入模型优先从模型列表中自动选择，也可手动填写。
- 自动推进默认关闭。开启后，以玩家每次发言为起点，最多追加 1—3 轮；发现未发送草稿时停止。
- 剧情选项具有独立总开关，默认关闭；支持“玩家行动（代入）”“场景入口”“第三人称叙事”和“混合”四种表达方式，以及 4—12 个选项。点击生成结果只写入 SillyTavern 真实聊天输入框，不触发发送，由玩家自己确认。
- 人格测试的单个答案只保存在当前页面；只有点击“完成测试并生成分析”或主动选择“跳过测试”时才调用分析接口。
- 玩家偏好测试从自主推进主页拆成独立全屏二级页面，包含 10 题情境题和 12 项可多选剧情体验。偏好档案是玩家级全局资料，首次完成后其他聊天直接复用；主页只显示摘要与折叠的完整分析，重新测试前必须确认覆盖，也可以跳过测试直接依据聊天分析。
- 时间线、人物状态、人物关系和伏笔直接展开在每楼摘要下；大总结单独保存连续性规则。
- 打开插件、切回“楼层摘要”、读到新楼层或最新楼层摘要完成时，自动定位到最新楼层。手机端保留触摸滚动，隐藏可见滚动条。
- 手机端楼层使用连续档案行而不是独立圆角卡片；底部导航为不透明实体栏，所有入口保持单行显示。偏好测试使用从“不同意”到“同意”的五级连续刻度，中点明确标为“中立 / 不知道”。
- 楼层标题、分隔线、状态标记和玩家原文区域使用更柔和的低对比色；手机底部导航单独使用系统楷体字体栈。
- NPC 是独立档案页面。玩家不选择剧情功能，由 AI 根据总摘要、获准发送的近期上下文、现有档案和玩家偏好自行判断。可手动触发建档，也可以在开启后由导演判断是否需要新增人物，并在剧情明确推进时更新既有 NPC 的年龄、人生阶段、工作、客观状态与成长状态。档案用详细经历解释性格和内部矛盾，禁止固定口癖、小动作与行为模板；不生成出场方式或剧情钩子，玩家可以编辑全部档案字段。

## 远端边界说明

摘要、剧情选项和推进导演默认只构造“总摘要”，不附带历史楼层原文；玩家也可以主动改为最近 1、3、5 楼。逐楼摘要必须额外发送目标楼层本身，才能生成该楼摘要。语义索引只使用摘要和结构化事实；零原文模式下，查询向量也只使用摘要。所有上述请求正文合计最多约 6500 token。如果使用酒馆当前 API，其他已安装扩展仍可能在 SillyTavern 的生成事件中修改请求；本扩展无法替第三方扩展作隐私保证。

自动推进分两步：导演接口生成一条推进指令，随后 SillyTavern 当前连接按正常聊天上下文续写。正常续写沿用酒馆本身的上下文策略，不属于额外摘要 API 的五楼边界。

## 本地查看

直接通过本地 HTTP 服务打开 `preview.html` 可查看桌面和手机响应式界面。静态预览不调用模型，也不代表真实 SillyTavern 运行验收。

## 安装与验收边界

当前目录是待安装扩展源码，没有写入或启用本机 SillyTavern。安装后仍需在真实 1.14.0 环境验证：扩展管理器显示、聊天切换、编辑、删除、滑动重选、刷新持久化、真实 API 请求、移动端触控与自动推进停止条件。
