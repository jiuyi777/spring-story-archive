# 春序档案 · 单蓝图

## 目标

把长篇聊天变成一份本地、可恢复、逐楼可追踪的剧情档案；远端摘要服务最多接触最近五楼原文。

## 红线

- 不把第六楼以前的原文放进摘要、选项或推进导演请求。
- 不默认开启自动推进。
- 不把 API Key 写入扩展设置、IndexedDB、日志或预览数据。
- 不在玩家输入框有草稿时触发自动推进。
- 不把静态检查称为真实酒馆验收。

## 第一版验收

1. 每个当前聊天楼层在列表中都有状态。
2. 缺失与失败楼层可重新生成。
3. 隐私负载测试证明只含目标楼层以内的最近五楼原文。
4. 第 100 楼或 token 上限触发压缩摘要。
5. 选项支持三种模式与 4—12 个数量。
6. 自动推进必须由玩家开启，并按轮数上限停止。
7. 桌面和 390px 宽手机预览可阅读、可操作。
